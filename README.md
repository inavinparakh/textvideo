# टाइपरायटर व्हिडिओ जनरेटर (Typewriter Video Generator)

तुम्ही टाकलेला मजकूर (मराठी / हिंदी / इंग्रजी) टाइपरायटर इफेक्टने टाइप होताना दाखवणारा व्हिडिओ तयार करणारं, पूर्णपणे ब्राउझर-मध्ये चालणारं वेब अ‍ॅप्लिकेशन. कोणताही सर्व्हर, बॅकएंड किंवा API की लागत नाही — `index.html` उघडा आणि वापरा.

## वैशिष्ट्ये

- मराठी/हिंदी (Devanagari) आणि इंग्रजी मजकूर सपोर्ट (Noto Sans Devanagari फॉन्ट)
- 3 व्हिडिओ आकार: लँडस्केप (16:9), स्क्वेअर (1:1), रील्स/स्टोरी (9:16)
- फॉन्ट साइझ, टायपिंग वेग, मजकूर/बॅकग्राउंड रंग, कर्सर ब्लिंक, शेवटचा थांबा — सर्व सेटिंग्ज कस्टमाइझ करता येतात
- ब्राउझरमध्येच रेकॉर्डिंग (Canvas + MediaRecorder API) — `.webm` व्हिडिओ फाइल थेट डाउनलोड होते

## वापर कसा करायचा

1. हे रिपॉझिटरी क्लोन करा किंवा फक्त `index.html` डाउनलोड करा
2. `index.html` कोणत्याही ब्राउझरमध्ये उघडा (Chrome किंवा Edge ची शिफारस — MediaRecorder सपोर्टसाठी)
3. डावीकडील पॅनलमध्ये मजकूर टाका, सेटिंग्ज निवडा
4. "▶ प्रिव्ह्यू चालवा" ने आधी बघा, नंतर "⏺ रेकॉर्ड आणि डाउनलोड" दाबा
5. रेकॉर्डिंग पूर्ण झाल्यावर डाउनलोड लिंकवर क्लिक करून `.webm` फाइल सेव्ह करा

## GitHub Pages वर होस्ट करणे (मोफत)

1. या फोल्डरमधील फाइल्स एका नवीन GitHub रिपॉझिटरीमध्ये पुश करा
2. रिपॉझिटरी Settings → Pages मध्ये जा
3. Source म्हणून `main` ब्रँच आणि `/ (root)` फोल्डर निवडा
4. काही मिनिटांत तुमचं अ‍ॅप `https://<username>.github.io/<repo-name>/` इथे लाइव्ह होईल

## टीप

- `.webm` फाइल बहुतेक व्हिडिओ एडिटर (CapCut, Premiere, DaVinci Resolve) आणि सोशल प्लॅटफॉर्मवर चालते. MP4 हवं असल्यास [CloudConvert](https://cloudconvert.com/webm-to-mp4) सारख्या फ्री टूलने किंवा `ffmpeg -i input.webm output.mp4` कमांडने कन्व्हर्ट करता येईल.
- Safari मध्ये MediaRecorder सपोर्ट मर्यादित आहे — रेकॉर्डिंगसाठी Chrome किंवा Edge वापरा.
- सर्व प्रोसेसिंग स्थानिक (local) आहे — तुमचा मजकूर कुठेही अपलोड होत नाही.
